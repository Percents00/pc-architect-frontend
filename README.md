# PC ARCHITECT — Frontend

Интерфейс конфигуратора ПК: каталог, проверка совместимости, регистрация, вход и личный кабинет с приватными сборками.

## Репозитории проекта

- [Бэкенд](https://github.com/Percents00/pc-architect-backend)
- [Документация](https://github.com/Percents00/pc-architect-docs)

## Запуск

Разместите репозитории в соседних папках `frontend` и `backend`. Настройте PostgreSQL и запустите Django по инструкции в [README бэкенда](https://github.com/Percents00/pc-architect-backend#readme). Откройте `http://127.0.0.1:8000/`.

Django обслуживает интерфейс и API с одного адреса. Отдельный сервер фронтенда и установка npm-пакетов не нужны. Открытие `index.html` как локального файла не загружает каталог и авторизацию.

## Файлы

| Файл | Назначение |
| --- | --- |
| `index.html`, `style.css` | Страница и оформление |
| `app.js` | Каталог, конструктор и личные сборки |
| `auth.js` | Авторизация и управление сеансом |
| `compatibility.js` | Проверка совместимости в браузере |

Документация проекта находится в репозитории [pc-architect-docs](https://github.com/Percents00/pc-architect-docs). Каталог комплектующих хранится в PostgreSQL; его начальные данные находятся в бэкенде.
